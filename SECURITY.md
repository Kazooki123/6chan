# Security Policy

Security is the most important part of **6chan**, and responsible disclosure is appreciated.

## Reportong a Security Issue

If you discover a security vulnerability, please avoid creating a **public issue**. Instead, privately contact 6chan's **maintainers & core contributors** with:

- A description of the issue
- Steps to reproduce/recreate it
- Potential Impacts
- Suggested fixes (optional)

A response will be provided as soon as possible, thanks.

## Supported Versions

At the moment, only the latest development version of 6chan is actively supported with security fixes.

## Scope

Examples of security issues include:

- Authentication bypasses
- SQL Injection (SQLi)
- Cross-site scripting (XSS)
- Remote code execution
- Sensitive information disclosure.

Thank you very much for helping and keeping the community safe.
