# Contributing to 6chan

First of, we appreciate you for wanting to contribute to this **imageboard** project!

> 6chan is a community-driven imageboard focused on **wholesome discussions** while **respecting freedom of speech**. Whether you're fixing bugs, improving documentations, and suggesting new ideas for the website, your contribution always matters to us alot! 🩷

## Dev Stack

6chan uses all of these:

- PHP (8+)
- PostgreSQL
- MinIO (storage buckets for developement)
- Fail2Ban (IP bannings)
- Mailer (simple SMTP for local development)

And finally, **Podman**!! 🦭

## Getting Started ^▽^

0. Fork the repo

1. Create a **new branch** for your changes

2. Make your changes and **test them first**

4. Commit your work with a clear and proper message.

5. Open a pull request, described what you've changed, and we'll review it ^_^

### Coding Style

- Keep your code simple and readable
- Follow the projects code style whenever possible ofc
- **AVOID** unnecessary dependencies
- Write comments only where they improve understanding

## Reporting Bugs

If you found a bug, please include:

- What happend
- What you expected to happen
- Steps to reproduce the bug
- PHP version and what OS you're in

## Feature Requests

New ideas and suggestions are very, very welcome.

**Before opening a feature request, please consider whether it fits the goals of 6chan and whether again it keeps the project lightweight or stable.**
