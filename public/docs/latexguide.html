LaTeX Guide

Use KaTeX to render math inline or in display mode inside post bodies.

Inline math

You typeYou get
\(E = mc^2\)
\(E = mc^2\)
$x^2 + y^2 = z^2$
$x^2 + y^2 = z^2$

Display math

You typeYou get
\[\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\]
\[\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\]
$$\int_0^1 x^2 dx = \frac13$$
$$\int_0^1 x^2 dx = \frac13$$

Notes

KaTeX supports most LaTeX syntax, but it does not run arbitrary HTML/JS.
